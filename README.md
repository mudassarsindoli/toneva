# Toneva

A simple web tool to trim and cut MP3 audio files. Pick the part you want, preview it, and download it.

**Live:** [toneva.vercel.app](https://toneva.vercel.app/)

## Why

Cutting a clip from an audio file shouldn't need heavy software or an account. Toneva keeps it to three steps: choose the section, preview it, download it.

## Features

- Trim and cut MP3 files
- Select the exact part you want to keep
- Preview before downloading
- Responsive layout for desktop and mobile

## Tech

- JavaScript
- Deployed on Vercel
